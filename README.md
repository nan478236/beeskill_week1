# BeeSkills Internship - Week 1

## Project
Personal Portfolio & Mini E-Commerce Website

## Technologies
- HTML: page structure and sections
- CSS: styling, Flexbox, CSS Grid and responsive layout
- JavaScript: mobile navigation, cart counter and contact form validation

## Assignment coverage
1. Personal portfolio: Home, About, Skills, Projects and Contact sections.
2. Responsive navigation: menu changes for smaller screens.
3. Form validation: checks empty fields and email format.
4. E-commerce landing page: product cards and Add to Cart counter.
5. Layout: Flexbox for navigation/skills and CSS Grid for cards.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new **Public** repository on GitHub, for example `beeskills-week1`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings -> Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site.
7. Copy the published website URL (it will look like `https://your-username.github.io/beeskills-week1/`).
8. Open the URL in a new tab and test it. Submit that live website URL in BeeSkills.

Replace the sample personal details with your own details before submitting.
